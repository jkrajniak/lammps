# API Contracts: Python Scripts for AdResS Verification

**Feature**: 003-force-based-adress-verification  
**Date**: 2025-01-24

## gen_dimers.py

### Purpose
Generate LAMMPS data file for dimer fluid system.

### Command-Line Interface

```bash
python gen_dimers.py [options]
```

**Options**:
- `--box-size Lx Ly Lz`: Box dimensions (default: 30 10 10)
- `--num-molecules N`: Number of dimer molecules (default: 100)
- `--bond-length r0`: Equilibrium bond length (default: 0.97)
- `--mass M`: Mass per atom (default: 1.0)
- `--output FILE`: Output data file name (default: system.data)
- `--seed S`: Random seed for orientations (optional)

### Input
None (all parameters via command-line or defaults)

### Output
- **File**: `system.data` (or specified output file)
- **Format**: Standard LAMMPS data file with `Atoms`, `Bonds`, `Masses` sections
- **Validation**: File must be parseable by LAMMPS without errors

### Exit Codes
- `0`: Success
- `1`: Error (invalid parameters, file write failure)

### Example
```bash
python gen_dimers.py --box-size 30 10 10 --num-molecules 200 --output system.data
```

## run_verification.py

### Purpose
Iterative verification manager that runs LAMMPS simulations and updates thermodynamic force table.

### Command-Line Interface

```bash
python run_verification.py [options]
```

**Options**:
- `--lammps-binary PATH`: Path to LAMMPS binary (default: ./lmp_serial)
- `--input-script FILE`: LAMMPS input script (default: in.adress_dimer)
- `--data-file FILE`: LAMMPS data file (default: system.data)
- `--max-iterations N`: Maximum iterations (default: 20)
- `--prefactor F`: IBI update prefactor (default: 0.5)
- `--target-density D`: Target density (default: 0.844)
- `--table-file FILE`: Thermodynamic force table file (default: thermo_force.table)
- `--plot-dir DIR`: Directory for plots (default: plots/)

### Input
- `system.data`: LAMMPS data file (generated by gen_dimers.py)
- `in.adress_dimer`: LAMMPS input script
- `thermo_force.table`: Thermodynamic force table (created if missing)

### Output
- **File**: `thermo_force.table` (updated each iteration)
- **File**: `density_profile.dat` (latest density profile)
- **Files**: `plots/iteration_N.png` (density profile plots)
- **Console**: Progress messages and convergence information

### Exit Codes
- `0`: Success (all iterations completed)
- `1`: Error (LAMMPS execution failure, file I/O error, invalid parameters)

### Example
```bash
python run_verification.py --max-iterations 20 --prefactor 0.5 --target-density 0.844
```

## Data File Formats

### LAMMPS Data File (`system.data`)

**Format**: Standard LAMMPS data file
```
LAMMPS data file

N atoms
M bonds
...

Masses

1 1.0

Atoms # molecular

1 1 1 0.0 0.0 0.0
2 1 2 0.97 0.0 0.0
...

Bonds

1 1 1 2
...
```

### Thermodynamic Force Table (`thermo_force.table`)

**Format**: LAMMPS table format
```
# Thermodynamic force table
# N points
N
x1 f1
x2 f2
...
xN fN
```

**Constraints**:
- First line: Comment (optional)
- Second line: Number of points N
- Subsequent lines: x f(x) pairs (space-separated)
- x values must be monotonically increasing

### Density Profile Output

**Format**: Space-separated values (from LAMMPS `fix ave/chunk`)
```
# Bin center, Density
x1 rho1
x2 rho2
...
```

## Error Handling

All scripts must:
1. Validate input parameters before execution
2. Check file existence before reading
3. Provide clear error messages for common failures:
   - LAMMPS binary not found
   - Missing input files
   - Invalid file formats
   - Numerical errors (division by zero, etc.)
4. Exit with appropriate exit codes
