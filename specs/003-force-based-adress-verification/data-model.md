# Data Model: Force-based AdResS Verification

**Feature**: 003-force-based-adress-verification  
**Date**: 2025-01-24

## Entities

### Dimer System

**Description**: Represents a fluid of diatomic molecules in a simulation box.

**Attributes**:
- `box_size`: Tuple (lx, ly, lz) - simulation box dimensions (e.g., 30 x 10 x 10)
- `num_molecules`: Integer - number of dimer molecules in system
- `num_atoms`: Integer - total number of atoms (2 * num_molecules)
- `num_bonds`: Integer - total number of bonds (1 * num_molecules)
- `bond_length`: Float - equilibrium bond length (default: 0.97)
- `mass_per_atom`: Float - mass of each atom (default: 1.0)
- `molecule_positions`: Array of shape (num_molecules, 3) - center-of-mass positions
- `molecule_orientations`: Array of shape (num_molecules, 3) - orientation vectors (normalized)

**Relationships**:
- Contains `num_molecules` Dimer Molecules
- Stored in LAMMPS data file format

**Validation Rules**:
- `num_molecules > 0`
- `num_atoms == 2 * num_molecules`
- `num_bonds == num_molecules`
- All molecule positions within box boundaries
- No overlapping molecules (enforced by lattice placement)

### Dimer Molecule

**Description**: A single diatomic molecule with 2 atoms connected by a bond.

**Attributes**:
- `molecule_id`: Integer - unique molecule identifier
- `atom1_id`: Integer - first atom ID
- `atom2_id`: Integer - second atom ID
- `bond_id`: Integer - bond ID connecting atom1 and atom2
- `com_position`: Array (3,) - center-of-mass position
- `orientation`: Array (3,) - orientation vector (normalized)
- `atom1_position`: Array (3,) - position of first atom
- `atom2_position`: Array (3,) - position of second atom

**Relationships**:
- Belongs to one Dimer System
- Contains 2 Atoms
- Contains 1 Bond

**Validation Rules**:
- `atom1_id != atom2_id`
- Bond length approximately equals specified bond_length (0.97)
- Atoms within box boundaries

### Thermodynamic Force Table

**Description**: Spatial force field used by LAMMPS to achieve flat density profile.

**Attributes**:
- `num_points`: Integer - number of spatial grid points
- `x_values`: Array (num_points,) - spatial coordinates along x-axis
- `force_values`: Array (num_points,) - force values at each grid point
- `x_min`: Float - minimum x coordinate
- `x_max`: Float - maximum x coordinate
- `dx`: Float - grid spacing

**Relationships**:
- Read by LAMMPS input script
- Updated by verification script each iteration

**Validation Rules**:
- `num_points > 0`
- `x_values` monotonically increasing
- `x_min < x_max`
- `dx > 0`
- All `x_values` within [x_min, x_max]

**State Transitions**:
- Initial state: All force values = 0.0
- Updated state: Force values updated via IBI formula each iteration

### Density Profile

**Description**: Spatial distribution of density across simulation box.

**Attributes**:
- `num_bins`: Integer - number of spatial bins
- `x_bin_centers`: Array (num_bins,) - center coordinates of each bin
- `density_values`: Array (num_bins,) - density value in each bin
- `target_density`: Float - target density value (default: 0.844)
- `iteration`: Integer - iteration number when profile was measured

**Relationships**:
- Generated by LAMMPS simulation
- Read by verification script
- Used to update Thermodynamic Force Table

**Validation Rules**:
- `num_bins > 0`
- All `density_values >= 0`
- `x_bin_centers` monotonically increasing
- `iteration >= 0`

### Verification Run

**Description**: Complete verification execution with multiple iterations.

**Attributes**:
- `max_iterations`: Integer - maximum number of iterations
- `prefactor`: Float - IBI update prefactor (default: 0.5)
- `target_density`: Float - target density (default: 0.844)
- `current_iteration`: Integer - current iteration number
- `converged`: Boolean - whether convergence achieved
- `density_profiles`: List of Density Profile objects - one per iteration

**Relationships**:
- Contains multiple Density Profile objects
- Updates Thermodynamic Force Table each iteration
- Uses Dimer System configuration

**Validation Rules**:
- `max_iterations > 0`
- `prefactor > 0` and `prefactor <= 1.0` (for stability)
- `current_iteration >= 0` and `current_iteration <= max_iterations`

## Data Flow

1. **System Generation**: `gen_dimers.py` → Creates Dimer System → Writes `system.data`
2. **Initialization**: `run_verification.py` → Creates Thermodynamic Force Table (all zeros) → Writes `thermo_force.table`
3. **Simulation Loop**:
   - LAMMPS reads `system.data` and `thermo_force.table`
   - LAMMPS runs simulation → Generates Density Profile
   - `run_verification.py` reads Density Profile
   - `run_verification.py` updates Thermodynamic Force Table using IBI formula
   - `run_verification.py` writes updated `thermo_force.table`
   - Repeat until max_iterations reached

## File Formats

### LAMMPS Data File (`system.data`)
- Standard LAMMPS format with sections: `Atoms`, `Bonds`, `Masses`
- Text format, human-readable

### Thermodynamic Force Table (`thermo_force.table`)
- LAMMPS table format: N header lines, then x f(x) pairs
- Format: `x_value force_value` (space-separated)

### Density Profile Output
- LAMMPS `fix ave/chunk` output format
- Typically: `bin_center density_value` (space-separated)
