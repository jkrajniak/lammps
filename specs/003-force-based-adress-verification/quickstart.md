# Quickstart: Force-based AdResS Verification

**Feature**: 003-force-based-adress-verification  
**Date**: 2025-01-24

## Prerequisites

1. **LAMMPS Binary**: Compiled LAMMPS binary available as `lmp_serial` (or specify path)
2. **Python Environment**: Python 3.8+ with numpy and matplotlib
3. **Cloud Environment**: Kaggle or Google Colab (or any Linux environment)

## Step-by-Step Guide

### Step 1: Generate Dimer System

Generate a LAMMPS data file for a dimer fluid system:

```bash
python gen_dimers.py --box-size 30 10 10 --num-molecules 200 --output system.data
```

This creates `system.data` with 200 dimer molecules in a 30x10x10 box.

**Verify**: Check that `system.data` exists and contains correct number of atoms (400) and bonds (200).

### Step 2: Run Verification Loop

Run the iterative verification to tune the thermodynamic force:

```bash
python run_verification.py --max-iterations 20 --prefactor 0.5 --target-density 0.844
```

This will:
1. Create initial `thermo_force.table` (all zeros)
2. Run LAMMPS simulation for each iteration
3. Read density profile from simulation
4. Update thermodynamic force using IBI formula
5. Generate plots in `plots/` directory

**Expected Behavior**:
- Density profile should converge toward target (0.844) over iterations
- Plots show convergence progress
- `thermo_force.table` is updated each iteration

### Step 3: Verify Results

Check the generated files:

1. **Density Profile Plot**: `plots/iteration_19.png` (or latest iteration)
   - Should show density profile close to target (0.844)
   - Profile should be relatively flat across all zones

2. **Final Thermodynamic Force**: `thermo_force.table`
   - Contains the converged force values
   - Can be used for subsequent simulations

3. **Latest Density Profile**: `density_profile.dat`
   - Contains the most recent density profile data

## Example Workflow (Complete)

```bash
# 1. Generate system
python gen_dimers.py --num-molecules 200 --output system.data
```

## Troubleshooting

### LAMMPS Binary Not Found
**Error**: `FileNotFoundError: lmp_serial not found`

**Solution**: Specify path to LAMMPS binary:
```bash
python run_verification.py --lammps-binary /path/to/lmp_serial
```

### Missing Input Files
**Error**: `FileNotFoundError: system.data`

**Solution**: Run `gen_dimers.py` first to generate the data file.

### Convergence Issues
**Symptom**: Density profile not converging

**Solutions**:
- Reduce prefactor: `--prefactor 0.1` (slower but more stable)
- Increase iterations: `--max-iterations 50`
- Check LAMMPS input script for correct zone definitions

### Numerical Instability
**Symptom**: Force values become very large or NaN

**Solution**: Reduce prefactor to smaller value (e.g., 0.1 or 0.05)
